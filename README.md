# 🏦 Bank Job Preparation — Preli + Written Strategy

> **Target:** Senior Officer (SO) / Officer (OG) / Officer (OC) এবং অন্যান্য ব্যাংকিং চাকরি

---

## 🎯 মূল কথা

যারা **SO / OG / OC** টার্গেট করছেন, তাদের জন্য এখন থেকেই সিরিয়াস হওয়ার সময়।

> ⚠️ **প্রিলিমিনারি পরীক্ষা দেওয়ার পর Written-এর প্রস্তুতি শুরু করলে অনেকটাই দেরি হয়ে যায়।**

তাই শুরু থেকেই:

**Preli + Written → একসঙ্গে প্রস্তুতি**

নিলে সবচেয়ে ভালো ফল পাওয়া যায়।

তাই প্রতিদিন অল্প অল্প করে লিখুন।

উদাহরণ:

```text
Daily

+
Vocabulary
+

+

+

+

```

## ⭐ Golden Rule

> **Preli-এর আগে Written-এর প্রস্তুতি নয়—Preli-এর শুরু থেকেই Written-এর প্রস্তুতি।**

### Daily Minimum Target

* ✅ 10 Math
* ✅ Vocabulary
* ✅ Grammar
* ✅ Current Affairs
* ✅ Banking/GK
* ✅ Translation Practice
* ✅ Writing Practice

> **Consistency > Last-minute Preparation**

প্রতিদিন অল্প অল্প করে প্রস্তুতি নিলে Preliminary এবং Written—দুটোর জন্যই শক্ত ভিত্তি তৈরি হবে।
